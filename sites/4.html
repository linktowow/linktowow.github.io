网站简介

MDN Web Docs 是一个面向 Web 开发者的开放技术文档平台，主要定位于提供有关开放 Web 技术的信息。相关内容侧重于 HTML、CSS、JavaScript 以及适用于网站和渐进式 Web 应用的 Web API。平台内容由开发者参与共建，强调技术准确性与跨浏览器实用性。其文档体系覆盖标记语言、样式系统、脚本语言、编程接口、网络协议、可访问性、安全机制、性能优化及现代前端实践等方向。术语表、指南、教程与参考文档共同构成结构化知识组织方式。中文（简体）为可用语言之一，支持用户切换并记忆偏好。平台采用知识共享许可协议授权，内容可被自由引用与再分发。整体风格体现中立性与社区协作特征，不突出单一厂商立场，亦未声明提供托管服务、执行环境、用户账户或商业化功能。

主要功能

提供按技术领域组织的参考文档与学习资源，包括 HTML 元素与属性、CSS 属性与选择器、JavaScript 语法与内置对象、Web API 接口说明等。每类技术下设参考、指南、教程等子栏目，例如 CSS 指南涵盖盒模型、动画、Flexbox 与布局方案；JavaScript 指南涉及控制流、对象操作与类使用；Web API 指南介绍 Fetch、History、Web Speech 等接口的实际应用方式。部分文档附有代码示例，支持在页面内直接查看效果。平台设有“学习区”，提供结构化入门路径，如 HTML 结构化内容、CSS 样式基础与布局、JavaScript 动态脚本等模块，适合初学者循序渐进掌握。工具类资源包括边框图像生成器、圆角生成器、阴影生成器、颜色格式转换器与形状生成器等实用辅助功能。文档页面提供语言切换选项，并显示当前内容的语言状态。用户可通过顶部搜索框查找关键词、API 名称或技术概念，也可按主题分类浏览。各文档页含“编辑此页”入口，允许贡献者提交修改建议。平台持续更新内容，最新修订记录可在对应页面的历史信息中追溯。兼容性数据随浏览器版本演进同步维护，标注主流浏览器对特性的支持情况。所有内容以静态网页形式交付，未声明集成实时调试、云环境或用户身份系统。

适用人群

前端开发人员适合用于日常查阅 HTML 元素行为、CSS 属性作用域、JavaScript 语法细节及 Web API 调用方式；后端或全栈开发者可参考 HTTP 协议规范、URI 结构、安全策略与 WebAssembly 等跨层技术说明；技术写作者可借鉴其术语统一性与文档组织逻辑，构建内部技术资料；教育者可利用学习模块设计教学路径，借助内联示例降低实操门槛；浏览器相关从业者可结合自身实现核对标准符合度；非技术角色如设计师或产品经理可借助基础指南理解前端约束与实现逻辑，提升协作效率。该平台适合需要权威、结构化、多语言 Web 技术说明的用户，不面向依赖可视化建站、在线 IDE 或运行时调试工具的场景，亦不提供编程语言通识教学以外的通用计算机知识。内容无地域访问限制，中文版本保持更新，但未声明覆盖全部英文内容或具备实时同步机制。
