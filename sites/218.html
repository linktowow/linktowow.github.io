Kimi

从长文本起家，到 Agent 产品化的“全栈知识工作者”助手

访问官网

网站简介

Kimi 是由月之暗面（Moonshot AI）自主研发的 AI 智能助手，以超长上下文能力起家，逐步演进为对话与 Agent 深度融合的生产力平台。用户可通过官网（kimi.com）直接使用网页版，或下载 iOS、Android、HarmonyOS 移动端应用，无需下载即可在浏览器中完成聊天、创作、研究和构建任务。

Kimi 的发展路径在国内 AI 助手中颇具辨识度：2023 年以约 20 万汉字上下文切入市场，2024 年将无损上下文推至约 200 万字，用“把论文、财报、合同丢进对话框”的演示建立品牌定锚。2025 年下半年起，产品重心明显转向 Agent 与可交付成果，官方将 Agent 定位为帮用户“成为全栈知识工作者”。模型层面，Kimi 提供 K2.6（快速对话与问答）、K3（综合能力最强，擅长 Agent 任务）、K3 Swarm（大规模搜索与批量处理）三款模型，用户可在输入框上方一键切换。Kimi 的 Agent 产品线已形成完整矩阵：通用 Agent 负责网站生成、PPT 制作、深度研究与文档处理；Agent 集群支持超 4000 次并行工具调用、协调最多 300 个子智能体；Kimi Code 面向开发者；Kimi Work 面向知识工作者的本地 Agent；Kimi Claw 则是零部署云端自动化平台。

主要功能

超长上下文与文件处理是 Kimi 的看家能力。支持 PDF、Word、Excel、PPT、图片、TXT 及视频文件（单个最高 100 MB），每个会话最多可上传 50 个文件，能够一次性处理多个文档并完成摘要、翻译、答疑。拍照解题功能对模糊照片和刁钻角度也有较好适应。

通用 Agent 让 Kimi 从“回答问题”升级为“交付成果”。用户描述需求后，Agent 自动规划任务、调用工具并产出可下载的交付物，包括网站代码、Office 文件、研究报告等。Agent 集群模式可调度多达 300 个子智能体，并行处理 4000 个步骤，将海量文献综述、全网深度调研、超长行业研报等原本耗时的工作压缩至分钟级交付。

Office 办公能力达到“人类专家级”水平。Kimi 支持 PPT、Word、Excel 与 PDF 的无损互转，可自动编写 Excel 复杂公式与图表，胜任 Word/PDF 的专业排版与批注，PPT 支持上传视觉参考定制风格。视觉编程支持上传设计稿、手绘图甚至操作录屏，自动生成结构清晰、可维护的专业代码，从交互布局到滚动动效均可像素级还原。

深度搜索与插件生态提供可信的专业分析。Kimi 接入万得、同花顺、标普等权威插件，专业数据随调随用，搜索时会提供精准信息来源。多端同步确保手机、电脑、网页之间的对话、文件与工作进度实时衔接。

Kimi Work 与 Kimi Claw 拓展了使用场景。Kimi Work 是面向知识工作者的桌面端本地 Agent，能够读写电脑上的本地文件、跨桌面应用自动化操作，适合长时间运行的任务；Kimi Claw 是零部署云端自动化平台，30 秒内即可启动一个持续运行的 AI 智能体，内置 5000+ 技能库，支持链式组合调用与多步骤自主规划。

适用人群

Kimi 的目标用户经历了清晰的战略演进。早期核心用户是学生、研究者和需要阅读长文档的白领，长文本能力精准匹配了读论文、读财报、审合同的高频痛点。

知识工作者与生产力用户是当前战略转向后的核心受众。无论是需要端到端交付网站、Office 文件、研究报告的职场人士，还是希望用 Agent 完成复杂调研的分析人员，Kimi 的 Agent 模式都提供了从“聊一轮”到“拿到成果”的完整链路。开发者可通过 Kimi Code 获得编程助手套件（含 CLI 工具与 VS Code 扩展），或通过开放平台 API 将 Kimi 能力集成到自有应用中。

创意工作者与个人用户同样受益。一句话生成 3A 级多人 3D 游戏、上传参考图一键生成个性化 PPT、视觉编程自动还原设计稿，这些能力大幅降低了复杂创意的实现门槛。日常问答、写作辅助、翻译、语音通话、拍照解题等功能，则覆盖了最广泛的轻量使用场景。

从长文本时代的“能吃长材料的助手”，到 Agent 时代的“全栈知识工作者”，Kimi 正在用可交付的成果证明：AI 助手的天花板，不是对话有多流畅，而是能替用户完成多少真正的工作。
