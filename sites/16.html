LibTV

LiblibAI 推出的一站式 AI 视频创作 Studio 平台

访问官网

网站简介

LibTV 是 LiblibAI 推出的一站式 AI 视频创作 Studio 平台，主要定位于支持专业视频创作与智能体协同工作的双模态生成环境。平台采用人类创作者与 AI Agent 并行接入的设计思路，相关内容侧重于在统一界面下同时提供图形化操作路径与程序化调用能力。人类用户可通过空间化画布完成从文本输入、分镜组织到动态成片的连续性工作流；开发者则可借助 Skill 接口将平台功能嵌入外部 Agent 框架，实现基于自然语言指令的视频生成任务。平台原生集成 Seedance 2.0、可灵 3.0 及 Happy Horse 1.0 等多模态视频生成模型，所有模型均以完整参数配置运行。其核心价值在于整合剧本生成、角色建模、运镜调度、灯光布设、景深控制、多机位输出与基础剪辑等环节，减少在不同 AI 工具间切换的操作成本，同时为自动化内容生产提供结构化能力出口。

主要功能

  • 无限画布节点工作流：画布支持向任意方向延展，允许放置文本、图片、视频、音频、脚本五类节点，节点之间通过连线建立数据传递关系，上游输出可直接作为下游输入源；支持对任一节点单独调整、替换模型或保存为可复用模板。
  • 剧本与分镜一体化生成：脚本节点可基于文本剧本、参考视频或角色图三种方式触发分镜生成；生成结果可一键拆分为独立图像节点，并支持批量转为动态视频片段。
  • 角色一致性管理：上传单张角色图后，系统可生成正面、侧面、背面三视图，提取并锁定关键视觉特征，用于保障多镜头中人物形象的稳定性。
  • 多角度可视化编辑器：提供鱼眼、倾斜、正面俯拍、正面仰拍、全景俯拍、背面视角等预设视角，配合水平环绕与垂直俯仰调节方式，辅助机位设定。
  • 灯光控制系统：支持主光源在左、顶、右、前、底、后六个方位的独立控制，内置多种风格化灯光预设，可通过拖拽方式实时调整光影效果。
  • 镜头聚焦与景深调节：提供焦点位置与虚化强度两项基本参数，用于模拟光学镜头的焦外过渡效果。
  • 多机位批量生成：支持以宫格形式同步生成多个景别素材，适用于前期视觉规划与镜头语言测试。
  • 剧情推演与画面延展：基于单张图像可生成连贯性推演序列，或对已有画面进行时间维度上的前后延伸，辅助故事节奏设计。
  • 视频精准剪辑模块：支持对生成片段进行裁切、拼接与基础调整，可直接删除错误片段，无需导出至第三方软件处理。
  • Agent 自动化 Skill 接口：开放标准化接口，支持将平台能力接入外部 Agent 框架，实现自然语言驱动的视频生成任务，如短剧生成、参考视频复刻、音频匹配成片、链接直生成片等。

适用人群

  • 专业影视与短剧从业者：适合用于需要精细控制角色表现、运镜逻辑与光影氛围的 TVC、品牌广告及连载短剧制作场景。
  • AI 原生内容创作者：适合用于以短视频创作为主的内容生产者，借助画布工作流一站式完成创意落地，降低工具链切换频率。
  • Agent 开发者与技术型用户：适合用于需将视频生成能力嵌入自动化流程的技术实践，例如构建对话式内容服务或定制化 AIGC 应用。
  • 电商与品牌运营方：适合用于高频产出信息流广告与产品展示类视频，利用参考视频复刻与链接直生等功能快速迭代视觉素材。
  • 音乐与创意工作室：适合用于需将音频内容快速转化为匹配视觉叙事的 MV 制作场景，依赖平台对节奏与情绪的响应能力。
  • 进阶 AI 爱好者与学习者：适合用于希望从基础文生视频向更具导演意识的影视化表达进阶的学习过程，借助灯光预设、分镜推演与运镜工具理解影像构成逻辑。
